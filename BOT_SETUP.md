# Настройки BotFather

Изменения не применялись к действующему боту.
В @BotFather выбери /mybots, Bakery Empire, Edit Bot.

Short description:
Булочная империя: развивай пекарню, открывай производства и строй свою империю.

Description (стартовый экран):
🥐 Тебе досталась маленькая пекарня от дедушки!
Выпекай, зарабатывай, открывай производства и нанимай помощников. Сможешь построить огромную булочную империю?
Нажми кнопку запуска, чтобы начать.

Commands (/setcommands):
start - Начать игру
help - Как играть и сохранять прогресс

Кнопка запуска: 🎮 Играть в Булочную империю
Адрес Mini App: https://t.me/bakeryempirebot/bakeryempire

Тексты /start, /help и ответ на обычное сообщение находятся в server/worker.mjs.
